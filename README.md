# Datheon Data Analytics & Power BI Internship Projects

This repository contains two completed exploratory data analysis projects using Python and Jupyter Notebook.

## 01 — Superstore Retail Sales EDA

Explores sales, profit, customer purchase volume, monthly seasonality, product categories, regions, customer segments, and discount sensitivity. Includes data cleaning, charts, and executive takeaways.

- Notebook: `01_Superstore_Sales_EDA/Superstore_Retail_Sales_EDA_Completed.ipynb`
- Cleaned data: `01_Superstore_Sales_EDA/superstore_sales_cleaned.csv`

## 02 — IBM Telco Customer Churn & Retention

Explores churn rate, tenure cohorts, contract types, payment methods, monthly charges, high-risk service combinations, and a predictive churn model. Includes a heatmap and executive takeaways. Retention by tenure is cross-sectional, not a longitudinal survival curve.

- Notebook: `02_Telco_Churn_Analysis/IBM_Telco_Churn_Retention_Completed.ipynb`
- Cleaned data: `02_Telco_Churn_Analysis/telco_customer_churn_cleaned.csv`

## Tools

Python, Jupyter Notebook, pandas, numpy, matplotlib, seaborn, scikit-learn.

## How to review

1. Open either `.ipynb` file directly on GitHub to see saved analysis and visualizations.
2. To rerun locally, install packages from `requirements.txt`.
3. Launch Jupyter Notebook, open the project notebook, and run its cells. Keep the corresponding CSV in the project folder. Internet access may be required for any original data download code.

## Notes

The repository contains analysis notebooks and cleaned datasets. It does **not** claim to contain a Power BI report. All insights should be evaluated against the included notebooks and data.
